🇹🇷 Plate Lookup

Enter a Turkish vehicle registration number (VRN) — civilian, commercial, or official/government — to see what it decodes to.

Type the 2-digit code first — the numeric keypad pops up automatically — then it jumps to the letters field. The letters box also takes CD/CC/CM (diplomatic) or JAA-style (gendarmerie) codes. For privacy, the last 2–4 digits aren't needed; the plate shown in results fills in a random number just so it looks like a real one.
